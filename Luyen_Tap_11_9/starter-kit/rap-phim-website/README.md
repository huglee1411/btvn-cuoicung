


# CineBox – Đặt vé xem phim mini

Website **đặt vé** *xem phim mini*, phục vụ nhu cầu tra cứu và đặt vé nhanh chóng.

## Cấu trúc thư mục dự án
| Thư mục | Nội dung | Chú Thích |
| :--- | :--- | :--- |
| `data/` | Chứa dữ liệu Excel | File bảng giá và đặt vé |
| `docs/` | Chứa tài liệu | Biên bản bàn giao dự án |
| `logs/` | Chứa file log | Nhật ký hoạt động server |

## Lệnh CLI liệt kê dự án
```powershell
Get-ChildItem -Force

```
